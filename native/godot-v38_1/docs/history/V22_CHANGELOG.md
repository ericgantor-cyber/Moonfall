# Moonfall Native v22 - Creature, Gear and Rift Art

- Eight native fauna families gain unique *additional* procedural anatomical detailing.
- Five regional guardians gain distinct crowns/headdresses.
- Three existing rift sites gain open-air dungeon-style arenas with arches and thematic props. Decorative-only, no path blocking or new game modes.
- Twelve new transparent equipment icons appear beside equip actions and above dropped gear.
- Full/Smooth graphics mode hides optional creature detailing and arena structures.
- No save schema changes or original hero/bestiary/release artwork modifications.
- Tested with headless Godot 4.7.2 on Linux. Windows gameplay unverified; unsigned editor-runtime binary.

# Moonfall: One Connected 3D Realm

This is an original combination of gameplay concepts, not copied game assets or proprietary code.

- **Tainted Grail: The Fall of Avalon:** dark-fantasy atmosphere, grounded exploration and moody lighting through existing Godot Forward+ settings.
- **Diablo IV:** region bosses, rift battles, rare item drops and equipment builds.
- **Assassin's Creed Valhalla:** advisory power ratings for each open-world region, without level locks.
- **World of Warcraft:** fishing, herbalism, mining, cooking, alchemy and smithing with shared crafting materials.
- **Hades II:** dodge/cast/attack feedback, combat combos and escalating fights, without a second game mode.

## Implemented integration

The Raven Atlas World page displays a power-aware recommendation built from *actual* regional power requirements, completed events and unsealed rifts. It also links to the **existing** Professions, Hero Skills and Inventory menus.

Completing a regional world event now grants a small bonus of an **existing material** to feed professions. The bonus is one material (two if any profession has reached level 25), awarded once via the event's existing completed flag **before** the normal checkpoint save. The regular event loot and progress systems remain unchanged.

Core play loop: **explore -> regional event -> gather & craft -> better gear -> rift/guardian -> explore farther**.

The system creates no new currency, save schema, game mode, gameplay stopwatch, art asset, or required character redesign. All six regions stay physically connected, and Z/Nyra's original character images are unchanged.

## Boundaries

Moonfall does not literally combine the commercial games, their engines, level designs, or copyrighted artwork. The existing original-game combat and quest mechanics remain Moonfall's own. Substantial environment, animation and encounter polish beyond the gameplay integration still requires future work.

# Moonfall v37.6: All-Systems Tips Codex

- 13 categories of searchable in-game tips, in a single read-only data file.
- Use **Esc/F10 > Tips** or **F1** during play. F1 while the Codex is active closes it. The category controls and search field support keyboard/controller focus.
- Search filters title, category and tip content. Eight matches are displayed per page with next/previous controls.
- Existing action buttons gain mouse-hover tooltips without modifying gameplay actions, layout data or images.
- A separate standalone menu or unsolicited repeated HUD banners are deliberately **not** added.
- Do not confuse offline source checks with verified Godot gameplay. A real Godot test and Windows build are still required.

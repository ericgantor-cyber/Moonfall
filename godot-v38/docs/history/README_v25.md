# Moonfall Native v25 Legacy Overhaul

Open `project.godot` with Godot 4.7.2. On Linux run `GODOT_BIN=/path/to/godot python3 tools/run_tests.py` from this folder. On Windows place Godot 4.7.2 under `Godot_4.7.2/`, then run `BUILD_WINDOWS.bat` (Windows hardware testing required).

See `V25_CHANGELOG.md` and `tests/v25_legacy_modernization.gd` for exact scope.

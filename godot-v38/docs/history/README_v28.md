# Moonfall Native v28 - Windows playtest

Download/extract the Windows ZIP. Double-click `MoonfallNative_v28.exe` on a 64-bit Windows 10/11 computer. No `.pck` is required. The game is an unsigned development/playtest build using the Godot Windows editor executable with its pack embedded. Windows GPU, controller, and installer behavior remain unverified.

Godot source: open `project.godot` using Godot 4.7.2. This v28 build optimizes *distant, fully idle* wildlife; active enemies and bosses keep their original update cadence.

Z and Nyra's supplied character artwork is preserved exactly. The original schema-2 saves are preserved; make a backup before switching builds.

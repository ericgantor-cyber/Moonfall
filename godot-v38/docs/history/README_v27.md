# Moonfall Native v27 - modular gameplay core

Open `project.godot` in Godot 4.7.2. Play the Godot scene or build using the existing Windows scripts. Z and Nyra's original art are unchanged.

Run all Godot regression suites (Linux):
`GODOT_BIN=/path/to/Godot_v4.7.2-stable_linux.x86_64 python3 tools/run_tests.py`

For v27-only: `GODOT_BIN=/path/to/godot python3 tools/run_tests.py v27_system_modules`

The same schema-2 save format is preserved. See V27_CHANGELOG.md. Windows GPU/controller testing remains pending.

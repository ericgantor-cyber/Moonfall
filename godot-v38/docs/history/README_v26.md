# Moonfall v26 Modular Core

Open `project.godot` in Godot 4.7.2. All original artwork is preserved.

To run the complete test suite on Linux:
`GODOT_BIN=/path/to/Godot_v4.7.2-stable_linux.x86_64 python3 tools/run_tests.py`

On Windows place official Godot 4.7.2 in `Godot_4.7.2/` and run `BUILD_WINDOWS.bat`.

See `V26_CHANGELOG.md`. Windows gameplay and the installer remain to be tested on Windows.

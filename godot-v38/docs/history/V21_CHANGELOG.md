# Moonfall Native v21 · Grand Biome Art expansion

- Added six distinct oversized regional sculptures/monuments, each with a newly drawn illustrated crest.
- Added 72 multi-part sculpted environment dioramas, 12 per region.
- Added 1,440 additional microprops using 18 MultiMesh batches (3 batches per region).
- Made art deterministic, non-colliding and automatically hidden by Smooth mode, preserving the invisible terrain grid and gameplay.
- Preserved all six connected regions, original hero/beast art files, and save schema 2.
- Regional art is still handcrafted procedural low-poly geometry; it is not professionally rigged or photorealistic.
- Source and Windows-packed runtime tested on Linux only; Windows gameplay remains unverified.

# Moonfall Native v15: Living Art motion pass

- Procedurally generated species/variant coat patterns are painted at runtime and reused. No external textures required.
- Limb stepping for land creatures, wing flapping for owls and undulating serpent bodies. These are cosmetic and do not alter physics collisions.
- Guardian phase-change coronas and capped impact pulses make transformations readable.
- Five small regional wisps per biome; cosmetic update limited to the nearby active region and disabled by Smooth graphics quality.
- Existing native save schema, original hero and beast images, six connected zones, combat, rifts, crafting and taming preserved.
- Windows single-file packaging retains the embedded PCK approach from v14.

**Visual limitation:** Generated 64x64 coats and mesh-driven motion are procedural prototype art, not professionally rigged or authored PBR assets.
**Testing limitation:** No Windows hardware or real controller/GPU testing in the Linux test environment.

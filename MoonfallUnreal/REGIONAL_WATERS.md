# Regional waters (preview authoring)
Author up to nine axis-aligned water PhysicsVolumes in DeepWatersPreview, one per province, at least 12 x 12 x 5 meters. Each requires a terrain floor and accessible approach; do not overlap existing geometry. Tag each with exactly one MoonfallFishingProvince_0 through _8. Run create_deep_waters_material.py first, select the volumes and run install_regional_fishing.py. Inspect the generated bank, steps, water plane and four gathering nodes per province, then save manually. The installer refuses duplicate region IDs and rolls back newly created actors on failure. Regional schools have separate stock; resource IDs 12–47 have independent cooldowns. No campaign map or save schema changes. Native editor placement and playtesting remain required.

# UE5 talent foundation

This PR introduces the original 141-node Might/Agility/Arcana constellation as portable, header-only C++17 rules under `Source/MoonfallUnreal/MoonfallTalentRules.h`. It validates rank limits, prerequisite chains, level gates, two earned points per level, and safe respec calculations. `tools/test_unreal_talent_rules.cpp` is compiled and executed in the Unreal source-check workflow.

**Scope:** Talent rules and catalog only. This PR does **not** activate talents in live combat, change saved game formats, show the talent web in gameplay, or alter Z/Nyra art. Those changes remain in stacked draft PRs #1121–#1124 and need reconciliation with current `main` controls and native UE5 Windows testing.

## V13 live-character rank persistence (draft integration)

The UE5 hero now holds a 141-rank in-memory talent ledger. Blueprint-accessible APIs query available points, inspect ranks, spend a talent point, and respec all points. Spending/respec use the same validated C++17 rules and immediately save to the existing world slot; failure rolls the rank ledger back without silently consuming points. Invalid V13 talent arrays (wrong length, negative/oversized ranks, unmet prerequisites, overspent budgets, invalid level gates) prevent restoration **before** checkpoint teleport and block autosave from overwriting the original file. V1-V12 saves load with all ranks at zero and continue to use their established world progress.

**Important gameplay boundary:** Validated flat talent bonuses now affect the live hero’s maximum health, mana, and stamina, with delta-only changes and no repeat-load stacking. Purchases and respecs roll back both ranks and resources on failed saves. **Offensive spell magic-damage and all melee-damage bonuses are connected** through valid, bounded talent multipliers. Might improves both equipped and unarmed melee hits, not just sword strikes. Arcana damage does not amplify healing, and neither combat path performs extra checks per frame. **Ranged-damage talent effects are not connected** because no matching native ranged-hit path was validated in this slice. The native HUD now renders an interactive 141-node constellation, with mouse selection, clickable Might/Agility/Arcana tabs, point spending, and a timed two-step full respec confirmation. The controller D-pad navigates nodes while the web is open, shoulder buttons change branch, A spends a point, B closes, and LT twice confirms reset. Keyboard K toggles the web; Enter spends; Backspace twice resets; Page Up/Down and Home/End navigate; Tab changes branch. **WASD and keyboard arrows remain movement-only**. The mouse wheel pans tiers. The world remains live in **all** normal gameplay menus: existing enemies and bosses still move, complete windups and can damage the hero while talents, inventory, spellbook, stats, atlas, options, or dialogue is open. The player cannot use combat or movement controls behind these panels. Real health loss triggers a short red menu overlay; on lethal damage the talent screen closes and clears any pending respec, while enemy attack chains cancel only if the hero is defeated, missing or no longer possessed. Native UE5 Windows compilation and interactive input testing are still required. Do not claim this PR produces a playable, fully effective talent tree or a verified native UE5 Windows build. Full UE5 5.4 compile, hands-on spend/respec, loading old saves, invalid-save rejection, and quit/relaunch tests are required before merging this persistence slice.
